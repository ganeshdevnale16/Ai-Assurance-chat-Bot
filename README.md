# Sadak Mitra – Virtual Assistant Demo

A demo government-style portal (**National Roads & Highways Department – Demo**) with a floating virtual assistant, **Sadak Mitra**.

> This is a fictional demonstration website by Devnale Globals. It is not affiliated with any government body.

## About the assistant
Sadak Mitra replies in a polite, professional tone. Some replies intentionally contain subtle issues (risky advice, misinformation, or asking for personal data) so the bot can be used for chatbot testing and evaluation. Do not treat its answers as real guidance.

Topics the bot understands: greeting, driving licence, e-challan, helmet/seat belt, drink driving, speeding, accidents, potholes/complaints, FASTag/toll, vehicle registration, thanks.

## Features
- Government portal layout: accessibility bar, A-/A/A+ font sizes, contrast (dark) mode, tricolour strip, notices/tenders tabs, news ticker
- Full **English / हिन्दी** language switch (site and chatbot)
- Floating chat icon, chat window with typing indicator, quick-reply chips, mobile full-screen

## Run locally
It is a single static file. Open `index.html` in a browser, or:
```bash
npx serve .
```

## Deploy
- **GitHub Pages:** Settings → Pages → Deploy from branch → `main` / root.
- **Render:** New → Static Site → publish directory `.` (no build command).
